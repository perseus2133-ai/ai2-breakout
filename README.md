# 🚀 ai2-breakout — 돌파 포착기

매일 아침, **막 상승을 시작한 종목**만 골라 카톡으로 알려준다.
[ai2](https://github.com/perseus2133-ai/ai2)의 실적 컨센서스 데이터를 결합해
**테마성 뻥튀기와 실적 기반 돌파를 구분**하는 것이 이 도구의 차별점이다.

## 왜 만들었나

관심 있던 종목이 급등한 뒤에야 발견하는 일이 반복된다.
2600종목을 매일 눈으로 훑는 건 불가능하므로, **돌파 초기 구간(D+0~3)** 만
자동으로 걸러낸다.

## 설계 근거 (실측 검증)

코스메카코리아(241710) 2026년 4~8월 일봉으로 검증:

| 접근 | 결과 |
|---|---|
| 20일 신고가 **단독** | ❌ 4/24·6/29·7/7·7/9 전부 헛발 (노이즈) |
| 신고가 + **거래량 배수** 결합 | ✅ 6회 신호 **전부 수익** (+12.8% ~ +53.1%) |

특히 8/06(+8.1% 돌파, 거래량 1.7배)은 거래량 문턱 2.0배에 걸려 놓쳤는데,
그날이 실제로는 **+28.7%의 시작점**이었다.
→ *가격이 5% 이상 강하게 뚫으면 거래량 문턱을 1.5배로 완화* 하는 규칙을 추가했다.
반대로 헛발 신호들은 돌파폭이 1.3% 미만이라 이 완화에 걸리지 않는다.

## Stage 분류

| Stage | 정의 | 용도 |
|---|---|---|
| 🔵 1 준비 | 변동성 수축(스퀴즈), 아직 안 터짐 | 관심종목 등록 |
| 🚀 **2 돌파** | **D+0~3, 신고가 + 거래량 폭발** | **★ 카톡 알림 대상** |
| 📈 3 진행 | D+4~20, 이미 상승 중 | 추격 주의 |
| 🔥 4 과열 | 20일 +60%↑ 또는 RSI 80↑ | 관망 |

## 신호 스코어 (가중 100)

| 축 | 비중 | 내용 |
|---|---|---|
| 돌파 | 30 | 20/60/120일 신고가 돌파폭 |
| 거래량 | 25 | 20일 평균 대비 배수 (가짜 신호를 거르는 핵심) |
| 수축→확장 | 15 | 볼린저 밴드폭 수축 후 해소 |
| 추세 | 10 | 이평 정배열, 60일선 위 |
| 수급 | 10 | 외인·기관 5일 순매수 (ai2) |
| **실적** | 10 | **컨센 상향률 (ai2 고유)** |

## 파이프라인

```
매일 06시 (KST)
  ├─ ai2 CSV·스냅샷 로드        (raw.githubusercontent)
  ├─ 유니버스 구성              컨센 보유 + 시총 1,000억↑ + 거래대금 10억↑
  ├─ 일봉 수집 (~75초)          네이버, 종목당 120거래일
  ├─ 신호 계산 → Stage 분류
  ├─ signals/YYYY-MM-DD.json 커밋   ← 성과 추적용 영구 기록
  └─ 📱 카카오톡 알림
```

시세는 매번 새로 수집하므로 저장소에 커밋하지 않는다(가벼움).
신호 JSON만 누적되어 **과거 신호의 실제 수익률을 상시 검증**할 수 있다.

## 실행

```bash
pip install -r requirements.txt

python run_daily.py          # 스캔 (신호 저장)
python run_daily.py --limit 50 --no-save   # 빠른 테스트
streamlit run app.py         # 대시보드
```

## 대시보드 탭

- **🚀 오늘의 돌파** — Stage 2 종목 카드 + 근거 + 미니 차트
- **🔵 돌파 임박** — 스퀴즈 상태(Stage 1) 관심종목
- **📜 신호 이력** — 날짜별 신호 아카이브
- **📊 성과 검증** — 과거 신호의 신호가 대비 수익률·승률

## 카카오톡 알림

ai2와 동일한 시크릿을 사용한다 (`KAKAO_REST_KEY`, `KAKAO_REFRESH_TOKEN`,
`KAKAO_CLIENT_SECRET`). 저장소 Settings > Secrets 에 등록하면 자동 발송된다.

```
🚀 돌파 포착 08/13
① 실리콘투 +13.0% 거래량9.5x 점수91
② 한국콜마 +22.8% 거래량9.4x 점수89
③ 코오롱글로벌 +13.5% 거래량28.4x 점수86
외 26종목
```

## ⚠️ 주의

투자 판단의 보조 도구다. 신호는 **확률적 우위**를 노리는 것이지 수익을 보장하지 않는다.
특히 Stage 3·4는 이미 상승한 구간이므로 추격 매수 위험이 크다.
